# MediSync Appointment System

A modern, comprehensive doctor appointment booking system built with React, Vite, and Tailwind CSS.

## Features
- User registration and login
- Doctor browsing and booking
- Admin and Doctor panels
- Clean UI with shadcn/ui

## Scripts
- \`npm run dev\` - Start development server
- \`npm run build\` - Build for production
- \`npm run preview\` - Preview production build locally
