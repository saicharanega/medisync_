# MediSync Full-Stack System

A comprehensive MERN stack doctor appointment booking system.

## Project Structure
- `/frontend` - React, Vite, and Tailwind CSS web application.
- `/backend` - Node.js, Express, and MongoDB API server.

## Running Locally

You will need two terminal tabs to run both the frontend and backend simultaneously.

**1. Start the Backend API**
```bash
cd backend
npm install
npm run dev
```

**2. Start the Frontend App**
```bash
cd frontend
npm install
npm run dev
```

The frontend will run on `http://localhost:8080/` and proxy `/api/*` requests to the backend natively.
